# 沐浴露瓶垂直领域模型训练与推理系统

## 项目概述

本项目是一个专业的模型训练与推理系统，专注于沐浴露瓶的文生图任务。系统集成了完整的模型训练、推理和管理功能，提供直观的Web可视化界面，实现了从数据标注到模型部署的全流程解决方案，并提供了美观的用户界面。
项目代码、部署手册、接口手册等在其他分支
